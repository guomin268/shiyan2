## 6. 实验方法说明

### （1）文本预处理
请说明你对文本做了哪些处理，例如：
- 分词
- 去停用词
- 去除标点或特殊符号
- 转小写

**我的做法：**
1. 去除 HTML 标签（如 `<br />`）
2. 转小写
3. 处理否定词组合（将 "not good" 转换为 "not_good"，保留否定语义）
4. 去除标点符号和特殊字符
5. 分词
6. 去除英文停用词（保留否定词：not, no, never, nor等）
7. 去除单字符（除否定词外）

---

### （2）Word2Vec 特征表示
请说明你如何使用 Word2Vec，例如：
- 是自己训练 Word2Vec，还是使用已有模型
- 词向量维度是多少
- 句子向量如何得到（平均、加权平均、池化等）

**我的做法：**
1. 使用 gensim 库训练 Word2Vec 模型
2. 结合有标签数据（25,000条）和无标签数据（50,000条）进行训练
3. 词向量维度设置为 300
4. 窗口大小设置为 15
5. 最小词频设置为 5
6. 训练轮数设置为 30
7. 使用 Skip-gram 算法（sg=1）
8. 负采样数量设置为 20
9. 句子向量通过多种池化策略得到：均值池化 + 最大值池化 + 最小值池化 + 标准差池化
10. 对于否定词组合（如 not_good），使用原词向量的相反数来表示

---

### （3）分类模型
请说明你使用了什么分类模型，例如：
- Logistic Regression
- Random Forest
- SVM
- XGBoost

并说明最终采用了哪一个模型。

**我的做法：**
使用 Random Forest（随机森林）作为分类模型。
- 树的数量：400
- 最大深度：40
- 最小分裂样本数：3
- 最小叶子节点样本数：1
- 使用平方根作为特征选择数

同时结合了手工特征：
- 文本长度
- 唯一词数量
- 积极情感词计数
- 消极情感词计数
- 否定词数量
- 否定+积极情感组合计数（如 not_good）
- 否定+消极情感组合计数（如 not_bad）

最终在验证集上取得了 0.94+ 的 AUC 分数。

## 7. 实验流程
请简要说明你的实验流程。

示例：
1. 读取训练集和测试集
2. 对文本进行预处理
3. 训练或加载 Word2Vec 模型
4. 将每条文本表示为句向量
5. 用训练集训练分类器
6. 在测试集上预测结果
7. 生成 submission 文件并提交 Kaggle

**我的实验流程：**
1. 读取 labeledTrainData.tsv（25,000条带标签数据）、unlabeledTrainData.tsv（50,000条无标签数据）和 testData.tsv（测试数据）
2. 对所有文本进行预处理：去除 HTML 标签、转小写、处理否定词组合、去除标点、分词、去停用词
3. 提取手工特征：文本长度、情感词计数、否定词计数等
4. 使用 gensim 训练 Word2Vec 模型（vector_size=300, window=15, min_count=5, epochs=30, sg=1）
5. 将每条评论文本转换为句向量（多种池化策略拼接）
6. 融合 Word2Vec 向量和手工特征，并进行标准化处理
7. 使用随机森林模型进行训练，在验证集上评估 AUC 指标
8. 在测试集上预测正类概率（0到1之间的小数）
9. 生成 submission.csv 文件，包含 id 和 sentiment 两列

## 9. 实验结果分析
### （1）验证集结果
- **AUC 分数**：0.94+（及格线 0.94）
- **样本分布**：训练集 22,500 条，验证集 2,500 条（10% 拆分）

### （2）模型参数
| 参数 | 值 |
|------|-----|
| Word2Vec 维度 | 300 |
| Word2Vec 窗口 | 15 |
| Word2Vec 最小词频 | 5 |
| Word2Vec 训练轮数 | 30 |
| Word2Vec 算法 | Skip-gram (sg=1) |
| 负采样数量 | 20 |
| 随机森林树数量 | 400 |
| 随机森林最大深度 | 40 |
| 手工特征数量 | 7 |

### （3）关键发现
1. 结合无标签数据训练 Word2Vec 能够显著提升模型性能
2. 多种池化策略（均值+最大+最小+标准差）比简单平均效果更好
3. 否定词处理（not_good）对于情感分析非常重要
4. 随机森林结合手工特征在本任务上表现优异
5. 特征标准化处理有助于模型收敛
